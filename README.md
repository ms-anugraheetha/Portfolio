# Portfolio — Anugraheetha Bin Saj

Editorial portfolio built with React, TypeScript, Tailwind CSS, Framer Motion, and Vite.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
npm run preview
```

## Customize

| File | Purpose |
|------|---------|
| `src/data/site.ts` | Name, email, GitHub, LinkedIn, CV path |
| `src/data/projects.ts` | Projects, demos, behind-the-build notes |
| `src/data/techStack.ts` | Skill categories |
| `public/cv.pdf` | Optional CV for download button |

## Deploy

Deploy the `dist` folder to [Vercel](https://vercel.com), [Netlify](https://netlify.com), or GitHub Pages.
